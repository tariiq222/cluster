# قائمة جاهزية التشغيل النهائي على الخادم

تُراجع مرة واحدة فقط بعد اكتمال تطوير R1 وR2 وR3 محلياً وقبل تشغيل المنصة على
الخادم الداخلي أو إدخال مستخدمين وبيانات حقيقية. لا تحجب هذه القائمة الانتقال
بين موجات التطوير. كل بند «نعم» مع
دليل (أمر ونتيجة، لقطة، أو سطر في سجل الحالة). أي «لا» يُسجَّل بسبب وموعد
معالجة، والقرار النهائي قرارك المسجل في سجل الحالة — لا أوزان ولا لجان ولا
مصفوفة توقيعات.

ملاحظة نطاق: التشغيل على خادم داخلي واحد وفق ADR-023؛ لذلك لا توجد بنود
توافر عالٍ أو HPA أو مناوبات — بديلها نسخ احتياطي مُجرَّب واستعادة موقوتة.
