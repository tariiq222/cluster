# العمليات التشغيلية المؤجلة من W1.1

أغلقت W1.1 محلياً بأدلة `make verify-w1-1` و`make verify-w1-1-local`. لا تعاد
هذه الأعمال ولا تحجب W1.2 أو برنامج الأيام الخمسة. البنود التالية تُنفذ مرة
واحدة في مرحلة التشغيل الآلي بعد اكتمال R1 وR2 وR3.

| # | العملية المؤجلة | الأمر/الدليل الآلي | شرط الإغلاق |
|---|---|---|---|
| 1 | تحقق CI على الالتزام النهائي | فحص CI المرتبط بـcommit الإطلاق | كل الوظائف خضراء |
| 2 | نشر VPS والرجوع | `make deploy-vps` ثم rollback وsmoke test | النشر والرجوع قابلان للتكرار |
| 3 | نسخ MySQL واستعادته | مهمة النسخ، checksum، restore في هدف معزول | الرحلة الحرجة تعمل بعد الاستعادة وRPO/RTO محققان |
| 4 | فحوص التشغيل والأمن | healthchecks، `make verify-boundaries`، فحوص الأسرار والعزل | لا فشل أمني أو معماري مفتوح |

لا توجد في هذا السجل ملاك بشر أو مراجعون أو لجان أو توقيعات أو UAT أو تدريب أو
قبول يدوي. يسجل التنفيذ التقني مخرجات الأوامر فقط في سجل الحالة. إعداد الخادم
(الجدار الناري والشبكة والمنافذ) يبقى خارج نطاق المستودع، مع بقاء فحوص Compose
والنسخ والاستعادة ضمن النطاق التقني.
