# ملخص الحالة التنفيذية

> **آخر مطابقة مع الكود:** 2026-08-13

Cluster منصة إدارية للتجمع الصحي. نطاق المنتج الحالي هو:

- الهوية والجلسات.
- التجمع والمنشآت والوحدات والأشخاص.
- الصلاحيات RBAC + ABAC بنطاق `cluster` أو `facility` أو `unit` أو `record_set`.
- المهام المستقلة، المشاركون، التعليقات، والوثائق المرتبطة بها.
- الإشعارات والبحث والتقارير المبنية على موارد النظام الحالية.
- التدقيق وإعدادات وتشغيل المنصة.

## الموديولات المتقاعدة

`WorkRecords` و`WorkDefinitions` و`Workflow` ليست جزءًا من المنتج الجاري. أزيلت مساراتها ومزوداتها وواجهاتها. تبقى بعض ملفات `docs/analysis/` القديمة كسجل تاريخي فقط، ولا تعد عقدًا أو وصفًا تنفيذيًا.

## مصادر الحقيقة

1. `docs/contracts/api/openapi.yaml` لعقد HTTP.
2. `apps/api/routes/web.php` للمسارات المنفذة.
3. `docs/architecture/module-catalog.md` و`apps/api/tests/Architecture/ModuleBoundariesTest.php` لحدود الموديولات والملكية.
4. الاختبارات الحالية لإثبات السلوك؛ لا تكفي وثيقة أو شاشة تجريبية وحدها لإثبات التشغيل.

## قاعدة الصلاحيات

الوصول لا يعتمد على المنشأة المختارة في الجلسة وحدها. يُبنى القرار من صلاحية المستخدم ونطاق التعيين والحقائق المستخرجة من المورد المستهدف. القوائم تُرشح كل عنصر، والقراءة أو التعديل لمورد غير مرئي تُحجب دون كشف وجوده.

راجع [`../architecture/ARCHITECTURE.md`](../architecture/ARCHITECTURE.md) للوصف المعماري الحالي، و[`00-overview.md`](00-overview.md) لفهرس التحليلات التاريخية.
