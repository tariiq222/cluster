# Cluster North Star

## الهدف النهائي

بناء منصة إدارية موحدة للتجمع الصحي تجعل العمل الإداري اليومي واضحًا، مضبوط الصلاحيات، وقابلًا للتتبع من الطلب حتى القرار والتنفيذ والتقرير، مع تقليل الاعتماد على Excel وWhatsApp والعمل اليدوي.

## النتيجة المطلوبة

- مساحة عمل عربية أولًا مع تكافؤ كامل للإنجليزية واتجاهي RTL/LTR.
- المستخدم يفهم دائمًا: الحالة الحالية، نطاقه الفعّال، الإجراء التالي المسموح، وأثر الإجراء.
- صلاحيات RBAC + ABAC مركزية وتفشل إلى المنع عند غياب دليل السماح.
- كل عملية حساسة قابلة للتدقيق عبر correlation IDs وaudit/outbox وسجل تغييرات واضح.
- عقود API موحدة ومصدرها OpenAPI، ولا توجد عقود ضمنية بين الواجهة والخلفية.
- Laravel Modular Monolith واضح الملكية والحدود، قابل للتوسع دون التحول المبكر إلى Microservices.
- تجربة هادئة، دقيقة، وعملية لإدارة الهيكل والصلاحيات والمهام والوثائق والتقارير وتشغيل المنصة.

## مبدأ القرار

أي تعديل يجب أن يقرب المشروع من هذه النتيجة، ويحافظ على الأمان وحدود الموديولات والعقود والاختبارات وتجربة الاستخدام. لا تُضاف بنية أو ميزة أو Dependency لمجرد أنها ممكنة تقنيًا.
