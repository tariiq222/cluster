# Cluster Current State

## الحالة المؤكدة

- Backend: Laravel modular monolith مع حدود موديولات واختبارات معمارية ملزمة.
- Frontend: React 19 + Vite + React Router + TanStack Query، مع إعادة بناء حديثة لنظام التصميم والشاشات.
- عقود API: OpenAPI هو المصدر الرسمي، وOrval يولد عميل الواجهة.
- الموديولات القائمة تشمل الهوية، الصلاحيات، المنظمة، سجلات العمل، المهام، الوثائق، الإشعارات، البحث، التقارير، التدقيق، وإعدادات المنصة.
- بوابات تحقق محلية موجودة في `Makefile` تشمل API وWeb والحدود المعمارية والعقود وE2E.
- `PRODUCT.md` و`DESIGN.md` و`docs/design/DESIGN-RULES.md` و`docs/design/PAGES.md` مراجع ملزمة للمنتج والواجهة.

## المرحلة الحالية

التركيز الحالي هو تثبيت المنصة بعد إعادة بناء الواجهة، إغلاق فجوات المنطق والتجربة، حماية الحدود المعمارية، وربط كل شاشة ببيانات وصلاحيات حقيقية دون توسيع النطاق تلقائيًا.

## قاعدة التحديث

يُحدّث هذا الملف فقط عند تغير جوهري في مرحلة المشروع أو بنيته أو حالة موديول رئيسي. لا يُستخدم كسجل يومي للتعديلات الصغيرة.
