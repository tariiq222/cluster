# Cluster Current State

## الحالة المؤكدة

- Backend: Laravel modular monolith.
- Frontend: React/Vite مع TanStack Query وReact Router.
- عقود API موحدة عبر OpenAPI وOrval.
- موديولات أساسية قائمة تشمل الهوية، الصلاحيات، المنظمة، المهام، الوثائق، الإشعارات، البحث، التقارير، وإعدادات المنصة.
- اختبارات API وWeb وArchitecture وE2E موجودة.
- بوابات تحقق محلية موجودة في Makefile.

## المرحلة الحالية

التركيز على استقرار المنصة، إغلاق الفجوات المنطقية، حماية الحدود المعمارية، وتحسين تجربة الاستخدام المبنية على بيانات حقيقية.

## ما يجب تحديثه

يُحدّث هذا الملف عند الانتقال إلى مرحلة جديدة أو عند تغير جوهري في حالة أحد الموديولات. لا يُستخدم كسجل يومي للتعديلات الصغيرة.
