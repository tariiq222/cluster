# Definition of Done

لا تعتبر المهمة مكتملة حتى يتحقق الآتي حسب نطاقها:

1. التغيير يطابق الهدف ومعايير القبول ولا يتجاوز النطاق.
2. لا توجد تعديلات جانبية غير مبررة.
3. اختبارات الوحدة/الميزة المرتبطة تعمل.
4. `make verify-boundaries` يعمل عند مساس التغيير بالمعمارية أو الموديولات.
5. `make lint-api` و`make analyse-api` يعملان لتغييرات API.
6. فحوص Web المناسبة تعمل لتغييرات الواجهة.
7. OpenAPI والعميل المولد متوافقان عند تغيير العقود.
8. تمت مراجعة الـdiff بحثًا عن أسرار، حذف بيانات، أو ضعف أمني.
9. تم تحديث التوثيق أو قرار معماري إذا غيّر التعديل قاعدة ثابتة.
