# Cluster Definition of Done

لا تعتبر المهمة مكتملة حتى يتحقق ما ينطبق على نطاقها:

1. النتيجة تطابق الهدف ومعايير القبول وعقد المهمة الحالي.
2. لا توجد تعديلات جانبية أو ملفات متأثرة دون مبرر مباشر.
3. تمت مراجعة الـdiff كاملًا، لا مخرجات النموذج فقط.
4. اختبارات الوحدة/الميزة المرتبطة تعمل.
5. `make verify-boundaries` يعمل عند المساس بالموديولات أو المعمارية.
6. `make lint-api` و`make analyse-api` يعملان لتغييرات API.
7. فحوص Web المناسبة تعمل لتغييرات الواجهة، مع الالتزام بقواعد التصميم وRTL/LTR.
8. OpenAPI والعميل المولد متوافقان عند تغيير العقود.
9. تمت مراجعة التغيير بحثًا عن أسرار، حذف بيانات، ضعف أمني، أو كسر للتوافق.
10. تم تحديث التوثيق أو القرار المعماري عندما يغير التعديل قاعدة ثابتة.
11. لا تبقى اختبارات مركزة أو skips أو TODOs أُضيفت لتجاوز فشل حقيقي.
12. يوضح ملخص التسليم: ما تغير، ما لم يتغير، أوامر التحقق، والمخاطر المتبقية.
