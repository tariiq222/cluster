# ذاكرة المشروع الخاصة

هذه هي الذاكرة الدائمة الوحيدة لهذا المشروع. تُحمّل في جلسات OpenCode التي تبدأ
من هذا المستودع، وتُحفظ معه حتى تبقى التعليمات متسقة، ولا تُنقل إلى مشاريع أخرى.

## قواعد الذاكرة

- احفظ هنا فقط تفضيلات المستخدم الثابتة، والسياق طويل الأجل، والقرارات المحلية
  التي لا تنتمي إلى وثائق المنتج المحكومة.
- حدّث هذه الذاكرة عندما يطلب المستخدم التذكر أو النسيان صراحة، أو عندما يصحح
  تفضيلاً ثابتاً يجب تطبيقه في الجلسات اللاحقة.
- لا تنشئ ملف ذاكرة موازياً، ولا تنسخ الخطط النشطة أو حالة التسليم إلى هنا.
- لا تحفظ أسراراً أو بيانات اعتماد أو بيانات صحية أو شخصية أو سجلات جلسات خام.
- عند التعارض، تتقدم تعليمات `AGENTS.md`، ثم `docs/`، ثم الكود والاختبارات
  والـ lockfiles على هذه الذاكرة.
- اجعل الإدخالات قصيرة، مؤرخة، وغير مكررة، واحذف المعلومة التي يطلب المستخدم
  نسيانها بدلاً من شطبها.
