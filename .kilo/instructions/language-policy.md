# Language Policy

- Communicate with the user in Arabic.
- Write all repository files, source code, code comments, configuration, agent prompts, plans, reviews, handoffs, execution packets, test names, logs, and inter-agent messages in English.
- Normalize Arabic user requests into English before delegation or persistence. Do not pass Arabic user text verbatim between agents.
- Preserve Arabic only when it is required product content, including localized UI copy, translations, fixtures, accessibility labels, or localization tests.
- Keep identifiers, API fields, capability names, module names, commands, file paths, and technical terminology in English.
- Do not translate internal prompts or agent handoffs into Arabic.
